# 0.11.0-beta.3：Core 2026.10 兼容补丁

本版只修改三个运行文件，复用现有 MCP SDK、工具名兼容层及结果校验。

- 保留 MCP 的 `isError` 标记与 content，避免 Pipecat 0.0.97 拼接文本时丢弃错误状态。
- 兼容 Core 2026.10 不带旧 `success` 字段的 GetLiveContext 成功响应；旧版 Core 的成功/失败格式和无前缀工具名继续支持。
- 启动目录查询拒绝 JSON-RPC / MCP 错误响应，不从错误内容构建实体目录。

新增 11 项响应契约测试，公开版全部 180 项 smoke 测试通过。验证包括新旧上下文、错误优先级、部分操作目标、空响应、异常不重发、SDK schema 转换及启动查询。Core 源码基线为 `2026.10.0b0`；不能将此结果等同于未来正式版实机验收。

HAOS 18.3 静态审查未发现需要专用代码修改的冲突。本版没有新增 OS 版本限制、Python/语音依赖升级、配置项或固件改动。完整镜像安装、HAOS 18.3 重启恢复及 Core 2026.10 / Voice PE 语音验收仍待完成；此前别名、特殊名称和工具同名边界限制仍见 [0.11.0-beta.2 说明](HOTFIX_20260916.md)。

## MCP 设置

Core 2026.10 新建 MCP 配置默认要求管理员并开放全部 LLM APIs；已有配置升级会保留原选择。家庭控制只需 Assist API。新装 2026.8 及以后环境可在现有 ha_mcp_url 中使用 `http://supervisor/core/api/mcp/assist`，或直连 Core 的 `/api/mcp/assist`；此入口按 Assist 暴露范围工作。已有自定义 URL 和旧环境配置保持显式设置，不自动改写或绕过权限。

刷新 add-on 仓库后应出现 `0.11.0-beta.3` 更新。先备份，再更新 add-on 并核对工具清单、默认名称/别名控制、天气、温度/亮度和语音续聊；Core 与 HAOS 分开升级并分别验收。
